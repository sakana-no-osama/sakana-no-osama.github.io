# 関東U-15女子 得点ランキング Codex運用ルール

## 最重要ルール

- 自動補完禁止
- 元データにない選手名、チーム名、得点、日付、試合結果を追加しない
- 不明点は HOLD として止める
- 0-0試合などの goals=0 診断行は goal_events CSV には残してよい
- goals=0 行はランキング集計から除外する
- goals>0 の行で team または player が空欄なら HOLD
- GitHub Pages公開前に必ず検証する
- git add . 禁止
- 公開反映は原則 index.html のみ
- 既存のバックアップや未追跡ファイルを削除しない

### 2025_D2_m31：確認済み12点の採用と既知HOLD差分

2026-09-28、運用責任者の明示指示により、次の運用ルールを正式化する。

- 試合結果は0–13である。
- 現在、根拠を確認できる得点イベントは12点のみである。
- 不明な1点について、選手名・得点時刻・内容を推測補完しない。
- 個人得点ランキングおよび得点イベント集計では、確認できた12点のみを採用する。
- 試合結果13点と得点イベント12点の差は、既知のHOLD差分として保持する。既存の score_mismatch:expected=13:actual=12 注記を維持する。
- 将来、一次情報から不明1点を確認できた場合のみ、根拠を記録したうえで更新を検討する。

この差分は新PC移行前から存在する既知データであり、それ自体をデータ破損・復旧失敗と判定しない。
新PC復旧検証では、既存CSVからの再生成一致、既存の各検証PASS、HTML生成・表示成功、および正式データの不変を確認できた場合、この既知差分を保持したまま復旧PASSと判定できる。
この扱いは本試合の13対12に限定する。他の未知の不一致には一般のHOLD条件を適用する。未確認1点のHOLDは解除しない。
Web取得、最新データ取得、Git push、公開は新PC復旧検証対象外であり、復旧PASSはこれらの動作や公開承認を意味しない。

## 成功条件

- 特定の得点数を固定の成功条件にしない
- 更新前の得点合計は比較用の参考値として扱い、更新後の成功条件には固定しない
- 更新後は `python tests/verify_2026_rankings.py` の結果を正とする
- 検証時点の `event_goals = rank_all_goals = team_all_goals` が一致
- ALL / DIV1 / DIV2 で個人合計とチーム合計が一致
- 2026年9月時点では218点であり、以後の正式な更新によって変動しうる
- 過去の194点は当時の確認済み値であり、将来更新後の固定条件ではない
- 得点合計または区分別合計が不一致の場合はHOLDまたはFAIL
- VERDICT=PASS
